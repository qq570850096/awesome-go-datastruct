# Linked List Exercises

This page indexes linked-list exercises implemented in Go. Use it after reading [Linked/README.md](README.md).

| File | Exercise | Practice focus |
| --- | --- | --- |
| `1.1 Reverse.go` | Reverse a linked list | Pointer rewiring |
| `1.2 RemoveDup.go` | Remove duplicates | Nested traversal, recursion, hash set |
| `1.3AddTwoList.go` | Add two number lists | Carry handling |
| `1.4MiddleReverse.go` | Reverse the second half | Slow and fast pointers |
| `1.5 FindLastK.go` | Find the kth node from the end | Two pointers |
| `1.6 FindEntry.go` | Find cycle entry or intersection | Fast and slow pointers |
| `1.7 ReverseTwo.go` | Swap nodes in pairs | Local pointer rotation |
| `1.8 ReverseK.go` | Reverse the first k nodes | Bounded reversal |
| `1.9 MeegeTwoList.go` | Merge sorted lists | Stable merge |
| `1.10 RemoveNode.go` | Remove a node by pointer | Value copy and next deletion |
| `1.11 CheckIntersect.go` | Check list intersection | Tail comparison and cycle trick |

## Study Tasks

- Draw the before and after pointer graph for each exercise.
- Add tests for nil input, one-node input, and boundary k values.
- Keep each exercise runnable through `go test ./Linked`.
