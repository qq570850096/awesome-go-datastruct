# Depth-First Search

## Goal

Learn recursive graph traversal and connected component counting.

## Prerequisites

Recursion and graph representation.

## Core Invariant

Visited state records which component each vertex belongs to.

## Complexity

Time O(V + E), Space O(V) for visited state and recursion depth.

## Practice Tasks

- Add tests for multiple connected components.
- Trace recursive entry and exit order.
- Compare DFS with stack-based traversal.
