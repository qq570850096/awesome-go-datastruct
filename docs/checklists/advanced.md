# Advanced Checklist

Use this checklist after Stage 3.

- [ ] I can state the invariant for a linked list, heap, tree, and graph traversal.
- [ ] I can write tests for empty, one-element, duplicate, missing, and boundary cases.
- [ ] I can compare average and worst-case complexity.
- [ ] I can explain why balanced trees keep operations logarithmic.
- [ ] I can choose between BFS and DFS for a graph problem.
- [ ] I can use union-find for connectivity problems.
- [ ] I can add a benchmark when a performance claim needs evidence.
