# Beginner Checklist

Use this checklist after Stage 1.

- [ ] I can run `go test ./BasicGo/...`.
- [ ] I can explain zero values and short variable declarations.
- [ ] I can write and run a table-driven test.
- [ ] I can explain value passing versus pointer passing.
- [ ] I can choose between value and pointer receivers.
- [ ] I can define a small interface and implement it with two types.
- [ ] I can return and wrap errors instead of using panic for ordinary failures.
