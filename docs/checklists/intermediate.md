# Intermediate Checklist

Use this checklist after Stage 2.

- [ ] I can start goroutines and wait for them safely.
- [ ] I can explain when to use channels and when to use a mutex.
- [ ] I can use `select` for timeout or fan-in behavior.
- [ ] I can propagate cancellation with `context.Context`.
- [ ] I can run `go test -race ./BasicGo/sharedvars` and understand why it matters.
- [ ] I can explain the tradeoff between generics and interfaces.
- [ ] I can describe why reflection and `unsafe` should be used carefully.
