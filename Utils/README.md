# Utilities

## Goal

Provide small shared interfaces and helper examples used by learning modules.

## Prerequisites

Interfaces and package basics.

## Core Invariant

Helpers should remain simple and should not hide the concept being taught.

## Complexity

Varies by helper.

## Practice Tasks

- Keep helpers documented.
- Avoid adding unrelated abstractions.
- Link helpers back to the topic that uses them.

## Test Command

```bash
go test ./Utils/...
```
